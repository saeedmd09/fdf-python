# FdF — 3D Wireframe Map Viewer

![Screenshot](docs/screenshot.png)

## Description

FdF is a Python application that reads height maps from FDF files and displays them as 3D wireframe models using isometric projection.

The application automatically scales and centers the map inside the window.

## Installation and Run

Python 3.12 or newer is required.
